# Do not use an en dash in responses, code, or output

Never use the en dash character (Unicode U+2013). Do not use an em dash (Unicode U+2014) either.

Use a comma, colon, parenthesis, hyphen, or period instead.

This applies to:

- Chat replies and explanations
- Source code and comments
- UI copy, docs, and filenames you generate
- Markdown and other output files

A normal hyphen in compound words (for example `built-in`) is fine. A minus sign in code is fine.
